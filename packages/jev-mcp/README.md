# Jev MCP（給 Claude Code 用）

讓 Claude Code 多一個工具 `jev_classify`：把「資料量大、每筆都問同一個封閉問題」的判斷，批次丟給 TypeSafe 的 Jev 模型——零點幾秒一筆、非常便宜。

- **choice**：每筆從你給的選項挑一個（例：這張是 bug／feature／other？）
- **score**：每筆依由低到高的量尺打 0~1 分（例：嚴重程度 外觀小問題 → 系統掛掉）

## 可以拿來做什麼

一句話判斷：**這一步的答案，能不能事先列成選項？能，而且資料很多筆、每筆都問同一個問題 → 交給 Jev。**

裝好之後不用記指令，直接跟 Claude 說就好，它會自己呼叫 `jev_classify`：

| 用途 | 可以這樣跟 Claude 說 |
|---|---|
| **留言／意見分類** | 「把這 500 則顧客留言用 Jev 分成：稱讚、抱怨、詢問、建議、其他」 |
| **工單／Bug 分流** | 「用 Jev 把這批工單分成前端、後端、資料庫、權限、其他，分好後依類別列給我」 |
| **任務歸類** | 「這 80 張任務用 Jev 判斷是 bug 還是新功能，信心度低的另外列出來」 |
| **名單初篩** | 「這 300 筆客戶名單用 Jev 依『是不是決策者』打分，只把前 30 名給我」 |
| **風險評分** | 「用 Jev 幫這些會員打流失風險分數（很穩定 → 快流失），高風險的整理成表」 |
| **客服逐字稿歸類** | 「把這些通話逐字稿用 Jev 歸到六種客服情境」 |
| **程式碼快篩** | 「這份 diff 用 Jev 快篩：有沒有改弱既有測試？有沒有把密碼或金鑰印進 log？只把有問題的細看」 |
| **文件／合約快篩** | 「這 50 份申請用 Jev 判斷符不符合條款，不符合或不確定的列出來我再看」 |
| **長逐字稿挑重點** | 「把這集訪談逐字稿切段，用 Jev 幫每段的精彩程度打分，給我前 10 段」 |
| **挑模型等級** | 「這幾個子工作用 Jev 判斷要用 haiku、sonnet 還是 opus，再分派」 |

**典型用法是「Jev 先海篩、Claude 再精讀」**：上千筆資料先讓 Jev 幾秒鐘分好或打好分，Claude 只深入處理篩出來的那幾十筆——又快又省。

參考量級：60 筆約 4 秒、約 0.002 美元（輸入每百萬 token 0.042 美元，輸出免費）。

## 不適合做什麼

- **需要寫出內容或理由**：Jev 只回選項和機率，不會寫文字、不會解釋
- **只有幾筆資料**：Claude 直接判斷比較快
- **需要高準度定論**：Jev 只做快篩，結果僅供參考；標 `uncertain`（信心度低）的一定要人或 Claude 複核，重要決策不要只看 Jev
- **沒有固定答案範圍的問題**：例如「這段程式碼該怎麼改？」——答案列不成選項

## 用得好的小訣竅

- **選項要寫具體情境，不要寫形容詞**：寫「找一個檔案的路徑、讀一個設定值」，不要寫「簡單的任務」
- **一定要留一個 none／other 選項**：沒有退路時 Jev 會被迫硬選一個，結果失真
- **打分的量尺由低到高寫兩端**：例如 `["外觀小問題", "系統掛掉"]`，回傳 0～1 分
- **一次最多 200 筆**；更多就分批，請 Claude 自動分批即可

## 安裝前準備

1. **Node.js 20 以上**：https://nodejs.org
2. **Claude Code**（`claude` 指令可在終端機執行）
3. **自己的 TypeSafe API key**：到 https://console.typesafe.ai 申請。費用算在你自己的帳號，**不要共用別人的 key**。

## 一鍵安裝

**Windows**：解壓縮後，雙擊 `install.cmd`，貼上 API key（輸入時不會顯示）。

**macOS／Linux**：
```bash
bash install.sh
```

安裝程式會：檢查 Node.js 與 Claude Code → 把 `jev-mcp.mjs` 放到 `~/.jev-mcp/` → 先驗證 API key（只查模型清單，不送任何資料）→ 註冊到 Claude Code（使用者層級，所有專案都能用）。

裝完**新開一個 Claude Code session** 就能用，例如跟 Claude 說「把這 200 則留言用 Jev 分成五類」。

## API key 存在哪

存成這個 MCP 的環境變數 `TYPESAFE_API_KEY`，寫在你電腦的 Claude Code 使用者設定 `~/.claude.json`（Windows：`C:\Users\<你>\.claude.json`）裡 jev 那一項。

- 是**明碼**存放（跟其他 MCP 的金鑰一樣）：這個檔案不要傳給別人、不要 commit 進 git
- 要換 key：重新執行安裝程式即可（會覆蓋舊的註冊）

## 其他

- 換 key／更新版本：重新執行安裝程式
- 移除：`claude mcp remove jev -s user`，再刪掉 `~/.jev-mcp/` 資料夾
- 資料會送到第三方 TypeSafe：只送判斷需要的文字，不要送帳密、金鑰、個資
- 進階參數（Windows）：`install.ps1 -ApiKey <key> -Name <註冊名稱> -InstallDir <安裝位置>`
