# AI-OmniCommander

## AI 協作開發指揮中心

---

## 這是什麼？

一個 MCP Server + Web UI，讓 Claude Code 能：

- 管理多個軟體開發專案
- 自動從 Asana 同步任務、從 SVN 抓規格文件
- 派多個 AI Agent 平行開發前後端
- 即時監控 Agent 進度

---

## 兩種操作方式

|            | Web UI                | Claude Code                     |
| ---------- | --------------------- | ------------------------------- |
| 操作       | 瀏覽器點擊            | 打字對話                        |
| 專案管理   | 表單設定              | create_project / update_project |
| 任務同步   | 按鈕同步              | sync_asana_tasks                |
| 執行任務   | 點 Execute → 產生指令 | 說「執行」自動派 Agent          |
| Agent 監控 | 即時終端、里程碑      | report_output 回報              |
| 文件上傳   | 拖拉上傳              | fetch_svn_specs 自動抓          |

**兩邊共用同一個 SQLite 資料庫，可以混合使用。**

---

## Web UI 功能

### 專案管理

- 建立專案（前端 / 後端路徑）
- 綁定 Asana 專案（自動同步任務）
- 設定 SVN 規格路徑（自動抓 SA/SD）
- 設定 Extra Prompt（附加給 Agent 的開發指示）
- 外部資料庫連線（查 schema 用）
- Gen Skills（自動分析專案產生 CLAUDE.md + skills）

### Agent 檢視

- 任務執行狀態（pending / in_progress / completed / failed）
- 進度輸出記錄
- 里程碑追蹤

### 補充

- Web UI 的專案設定、任務管理，在 Claude Code 也都能透過 MCP 工具操作
- 兩邊資料即時同步

### 全域設定

- SVN 帳密
- Asana Personal Access Token

## MCP 工具一覽

Claude Code 啟動時自動載入，不需要開 Web Server。

### 專案管理

- `list_projects` — 列出所有專案
- `create_project` — 建立專案（可直接指定 Asana 專案 GID）
- `update_project` — 更新專案設定
- `set_extra_prompt` — 設定專案 Extra Prompt（前端/後端）
- `set_global_config` — 設定 SVN 帳密、Asana PAT（不用手動改 DB）

### 任務管理

- `sync_asana_tasks` — 從 Asana 同步任務（直打 REST API）
- `list_pending_tasks` — 列出待處理任務
- `create_task` — 建立任務
- `update_task_status` — 更新狀態（in_progress / completed / failed）
- `list_asana_projects` — 列出 Asana 專案（找 GID 綁定用）
- `get_asana_task_comments` — 讀 Asana 任務的評論討論串

### 文件管理

- `fetch_svn_specs` — 從 SVN 自動抓取 SA/SD（含 SHA-256 快取）
- `fetch_task_attachments` — 從 Asana 下載任務附件圖片
- `get_documents` / `read_document` — 列出 / 讀取文件

### 資料庫

- `query_external_db` — 查詢專案綁定的外部 DB（列表、表結構、SELECT）

### 進度回報

- `report_output` — 回報執行輸出到 Web UI
- `report_milestone` — 回報里程碑
- `get_execution_plan` — 取得完整執行計畫

## Web UI → Claude Code

Web UI 選好任務後，產生一段指令，貼到 Claude Code 就能執行：

```
請透過 OmniCommander MCP 執行任務 60385068-...。

步驟：
1. 呼叫 get_execution_plan("60385068-...") 取得完整執行計畫
2. 使用 Agent tool 派出 subagent，將執行計畫作為 prompt
3. Subagent 會自動呼叫 report_output、report_milestone 回報進度
4. 完成後呼叫 update_task_status("completed", "摘要")
```

貼入 Claude Code 後，AI 自動跑完整個流程，Web UI 同步顯示進度。

## Agent 開發流程

每個 Agent 被派出後會自動：

**1. 讀專案規範**

- 讀 workspace 的 CLAUDE.md（架構、命名、規則）
- 讀 .claude/skills/（開發技能）
- 嚴格遵循專案自己的規範

**2. 讀規格文件**

- SA 文件 → 畫面欄位、按鈕文字、操作流程
- SD 文件 → API 路徑、參數名、SQL
- Axure 原型 → UI 結構確認
- 欄位名從規格逐字抄，不自己編造

**3. 品質規範**

- 後端寫 code 前先做效能分析（資料量、查詢條件、N+1）
- 完成後做安全弱點檢查（SQL injection、權限、輸入驗證）
- 編譯驗證通過才算完成

**4. 回報進度**

- report_output → Web UI 即時顯示
- report_milestone → 重要節點
- update_task_status → 完成 / 失敗

## SVN 規格自動抓取

```
任務名稱：WA04_已轉派工作清單
  → 提取功能代碼：WA04 → 根代碼：WA
  → SVN 搜尋：WA流程作業區/
  → 下載 SPEC_WA04_已轉派工作清單_v0.2.docx
  → 自動轉 Markdown
```

三層快取避免重複下載：

1. SVN 日期沒變 → 不下載
2. SHA-256 hash 沒變 → 不重新轉換
3. DB 已有記錄 → 直接使用

## Asana 任務整合

- MCP 工具直接用 PAT 打 Asana REST API
- 不需要開 Web Server
- 自動分類（前端/後端/bug/feature）
- 附件圖片自動下載
- 任務名稱自動匹配 SVN 規格文件

## 專案 Extra Prompt

每個專案可設定額外指示，自動注入到每個 Agent：

```
前端程式 UI 及操作請依照 skill 與 SA 文件為主，
SD 文件只用來看 API URL 欄位名稱。
請勿用 SD 文件修改前端畫面程式。
不准自己 commit。
```

不同專案可以有不同的指示，Agent 會自動遵循。

## 可安裝到任何專案

不限定在 ai-omni-commander 目錄中使用。在你的專案加一個 `.mcp.json`：

```json
{
	"mcpServers": {
		"omni-commander": {
			"command": "node",
			"args": ["/path/to/ai-omni-commander/server/dist/mcp-entry.js"],
			"env": { "DB_PATH": "/path/to/ai-omni-commander/data/omni.db" }
		}
	}
}
```

就能在任何專案的 Claude Code 對話中使用所有 MCP 工具。

## 安裝與啟動

```bash
git clone https://github.com/simon040102/ai-omni-commander.git
cd ai-omni-commander && git checkout OmniCommander_MCP
pnpm install && pnpm build
```

**純 Claude Code：**

```bash
claude    # MCP Server 自動啟動
```

**搭配 Web UI：**

```bash
pnpm dev  # Server:3457 + Web UI:5174
claude    # 另開終端
```
